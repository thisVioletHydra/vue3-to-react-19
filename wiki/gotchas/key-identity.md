# key: не индекс, и кнопка «убить инстанс»

## В чём проблема

React сверяет списки по `key`. Стабильный id сущности говорит «это тот же товар». Индекс говорит «третья дырка в массиве». После фильтра и сортировки третья дырка — уже другой товар, а инпут внутри оставляет старый текст.

Вторая половина: смена `key` у компонента — React **выбрасывает** инстанс и создаёт новый. Внутренний стейт обнуляется. Это легальный сброс формы. Это же случайное убийство стейта.

## Как не делать

- `key={index}` на списке, который фильтруется или сортируется.
- `key={Math.random()}` на каждый рендер.
- `key={filters}` объектом — ссылка новая, инстанс умирает каждый раз.
- Игнорировать warning про missing key.

## Как надо

`key={item.id}`. Сброс черновика редактора при смене карточки — `key={itemId}` на форме, не `useEffect(() => setValue(title), [title])`. На собесе: ключ — идентичность, не порядковый номер; смена ключа = unmount + mount.

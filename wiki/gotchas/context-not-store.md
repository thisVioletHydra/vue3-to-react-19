# Context — не Pinia

## В чём проблема

Context доставляет значение вниз без пропсов. Любой `setState` у провайдера перерисовывает **всех** потребителей. Тема и локаль меняются редко — ок. Список товаров с сервера в Context — любой чих каталога дёргает хедер, футер и соседа.

## Как не делать

- Кладёшь API-ответ в Context «чтобы не прокидывать пропсы».
- Корзину через 8 слоёв Context вместо стора.
- Потом мемоизируешь всё дерево, потому что «Context тормозит».

## Как надо

Context: тема, текущий пользователь как факт сессии, локаль. Каталог — Query. Корзина и UI-флаги далеко от клика — Zustand. На собесе: Context ≠ state manager; это канал, не кэш и не стор.

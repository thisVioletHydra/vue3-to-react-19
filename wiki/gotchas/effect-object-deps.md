# Объект в зависимостях эффекта каждый раз новый

## В чём проблема

`useEffect(() => { fetch(url); }, [{ page, q }]);` — литерал объекта создаётся каждый рендер, ссылка новая, эффект каждый раз. Функция, объявленная в компоненте, тоже новая ссылка каждый запуск.

## Как не делать

- Класть в deps объект или массив, который собираешь в этом же рендере.
- Лечить всё `useMemo` / `useCallback` «на всякий».
- Выключать eslint/oxlint на exhaustive-deps вместо того чтобы упростить зависимости.

## Как надо

Примитивы: `[page, q]`. Данные с сервера — Query с ключом `['items', page, q]`, не ручной эффект. `useMemo` — когда расчёт реально тяжёлый, не чтобы заткнуть ссылку. В 2026 React Compiler часть этого делает сам. На собесе: deps сравниваются через `Object.is`; новая ссылка = новый запуск.

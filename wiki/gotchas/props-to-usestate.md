# Скопировал проп в useState — проп дальше можно не присылать

## В чём проблема

```ts
function Editor({ title }: { title: string }) {
  const [value, setValue] = useState(title);
}
```

`useState(title)` читает аргумент **один раз** при монтировании. Родитель прислал новый `title` — инпут молчит. Во Vue `ref(props.title)` без watch — та же дыра. Туториалы React показывают «стейт из пропа» и не договаривают.

## Как не делать

- Копировать проп в стейт «на всякий» и ждать синхронизации.
- `useEffect(() => { setValue(title); }, [title]);` — эффект синхронизирует стейт со стейтом. Запах: данные лежат не там.
- Держать и проп, и копию, и не понимать, кто источник правды.

## Как надо

Поле всегда следует за пропом — рисуй `title` напрямую, без стейта. Черновик редактора — копия ок, сброс при смене карточки через `key={itemId}` на форме. На собесе: initial state ≠ derived state; сброс инстанса — `key`, не эффект.

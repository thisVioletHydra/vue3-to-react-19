# Zustand: подписался на весь стор

## В чём проблема

`useStore()` без селектора подписывает компонент на любой чих. Кликнул «сайдбар» — перерисовалась сетка каталога. Во Pinia ты тоже можешь взять весь стор, но селектор — базовая гигиена, не микрооптимизация.

## Как не делать

```ts
const store = useStore();
return <span>{store.cartCount}</span>;
```

Хедер читает всё, ререндер от любой экшена.

## Как надо

```ts
const cartCount = useStore((s) => s.cartCount);
```

Нужны два поля — два вызова или один селектор, который возвращает примитив / кортеж так, как принято в вашей версии Zustand (сравнение по умолчанию — `Object.is` на результат селектора). API-ответ в стор не кладём. На собесе: селектор режет ререндеры; стор — клиентский стейт, не кэш сервера.

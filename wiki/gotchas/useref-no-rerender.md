# useRef не обновляет экран

## В чём проблема

Vue `ref(0)` — реактивный ящик: меняешь `.value`, шаблон обновляется. React `useRef` — коробка `{ current }`. Запись в `current` **не** ставит рендер в очередь. Компонент-функция не запускается заново. На экране старое, в коробке новое.

Имя одно, модель разная. После Vue рука пишет `ref` на всё подряд.

## Как не делать

- Счётчик или текст на экране через `const n = useRef(0); n.current += 1` и ждать UI.
- Класть в ref объект и мутировать поля «как reactive».
- Путать с `useState`: «ref же тоже между рендерами живёт» — живёт, но молча.

## Как надо

На экране — `useState`. `useRef` для DOM-узла (`inputRef.current.focus()`) и для «запомнить между запусками без отрисовки» (актуальный колбэк в подписке, id таймера). На собесе: ref — мутабельный ящик без рендера, state — снимок, который заказывает новый запуск функции.

# Ребёнок не возвращает данные родителю

## В чём проблема

Компонент — не функция, из которой родитель получает число или объект. Ты вставил его в дерево, он рисует UI. `return` у ребёнка — **разметка**, не «верни выбранный id». Импорт модуля даёт компонент-функцию, не живой инстанс.

Во Vue та же дыра, про неё молчат. `v-model` / `emit` — сахар над колбэком, не «return из ребёнка».

## Как не делать

- Мутировать проп: `props.user.name = 'x'`. Во Vue консоль орёт. В React часто тихо: объект родителя портится, рендера нет.
- `let selected = null` в файле и импорт в обоих — кривой глобальный стор без подписки. HMR и второй инстанс едут.
- Vue: `$parent`, event bus, `defineExpose` + `child.getData()`.
- React: `useImperativeHandle` + `childRef.current.getValues()`. Для фокуса инпута — ок. Для «достать форму, потому что стейт не туда положил» — дыра в модели данных.

## Как надо

Стейт живёт там, где нужен обоим. Выбранная карточка — `selectedId` в родителе, вниз значение, вверх `onSelect`. Во Vue это `v-model` / `emit`, в React — `value` + `onChange`. На собесе это lift state up, не «я достаю данные из ребёнка».

Далеко тащить пропсы через 4 слоя — Zustand, как Pinia. Данные с сервера — Query, оба читают ключ. В каталоге `useImperativeHandle` не используем.

# Strict Mode: эффект дважды в dev

## В чём проблема

React 19 в разработке монтирует, чистит, монтирует снова. Ловит отсутствие cleanup. На проде один раз. Fetch в эффекте без отмены улетает дважды; при быстрой смене `id` старый ответ может перезаписать новый — это уже и на проде гонка, не только Strict Mode.

## Как не делать

- Выключить Strict Mode, «чтобы перестало двоиться».
- Fetch без `AbortController` / без флага `ignore`.
- Считать двойной вызов в dev багом React и игнорировать cleanup.

## Как надо

Эффект возвращает cleanup: abort, `clearInterval`, отписка. Ручной fetch дня 2 — с отменой. Потом Query, гонку решает сам. На собесе: Strict Mode в dev специально бьёт эффекты дважды; прод так не живёт, но гонка без abort живёт.

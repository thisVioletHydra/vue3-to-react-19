# CSS Modules

## Зачем

Стили каталога без глобальной каши имён на ранних днях ядра. Файл `Card.module.css`, классы уникальны после сборки. С капстоуна и трека 1b новые экраны — [Tailwind](tailwind.md); Modules не запрещены для мелкого legacy в проекте.

## Как не делать

- Один гигантский `index.css` на все карточки с `.item1` `.item2`.
- Inline-стили на каждую мелочь «потому что модули сложно».
- Урок BEM на десять страниц. Модуль уже изолирует имя.

## Как надо

```tsx
import styles from './Card.module.css';

<article className={styles.card}>
```

Глобальный сброс — тонкий `index.css`. Остальное рядом с компонентом. UI-кит (MUI/Ant) в спринт не тащим.

## Шаги

1. Когда сетка карточек появится — `Card.module.css` рядом с карточкой.
2. Класс из модуля на корне карточки, не из глобала.
3. Две карточки не перетирают стили друг друга.
4. Не просим ревью «центруй вот так» — это твой CSS.

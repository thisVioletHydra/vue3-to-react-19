# RBAC UI

## Зачем

Мульти-тенантный admin: эмитент, брокер, инвестор, compliance, regulator — разный UI и колонки. Бэкенд режет данные; фронт не показывает то, чего роль не должна видеть (и не зовёт лишние хуки криво).

## Как не делать

- `if (role === 'x') useQuery(...)` — хуки в условии. См. [role-in-render](../gotchas/role-in-render.md).
- Прятать кнопки только CSS-ом, а API всё равно бить без права — ок для демо, на собесе скажи что авторитет у сервера.
- Пять копий одной страницы «для каждой роли».

## Как надо

Роль в Zustand (или из JWT-клеймов в проде). Меню и колонки — конфиг `Record<Role, ...>` / фильтр массива. Query с `enabled` по праву, хук вызывается всегда. На собесе: UI-гард vs server RBAC.

## Шаги

1. Смена C: тип ролей + стор `useSessionStore`.
2. Переключатель роли в хедере (только для демо).
3. Таблица операций: разные колонки для compliance vs investor.
4. Чек: смена роли без ремаунта всего app через костыли.

# Vite

## Зачем

Дев-сервер и сборка каталога. ESM, быстрый HMR. Во Vue у тебя уже был Vite с `vue`. Здесь тот же инструмент, другой плагин: `@vitejs/plugin-react`. Webpack в вакансиях ещё мелькает — на собесе: Vite для дев и ESM, Webpack — старые монолиты.

## Как не делать

- Поднимать CRA / `react-scripts` в 2026.
- Искать «куда делся index.html» в `src` — у Vite html в корне пакета.
- Тащить в этот спринт тонкую настройку роллера «потому что так в банке».

## Как надо

Проект уже в `01-react/`. Точка входа `index.html` → `src/main.tsx`. Strict Mode включён — эффекты в dev двоятся, это норма, см. [strict-mode](../gotchas/strict-mode-double-effect.md).

## Шаги

1. `cd 01-react && npm run dev`
2. Открыть URL из терминала, увидеть заглушку каталога.
3. Поменять текст в `src/App.tsx`, сохранить — страница обновляется без перезагрузки. Понял HMR.
4. Сборку `npm run build` в этот день не обязательно. Когда дойдёшь до капстоуна — один раз проверить, что `tsc -b` проходит.

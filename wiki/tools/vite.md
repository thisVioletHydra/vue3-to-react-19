# Vite

## Зачем

Дев-сервер и сборка каталога. ESM, быстрый HMR. Во Vue у тебя уже был Vite с `vue`. Здесь тот же инструмент, другой плагин: `@vitejs/plugin-react`. Webpack в вакансиях ещё мелькает — на собесе: Vite для дев и ESM, Webpack — старые монолиты.

## Как не делать

- Поднимать CRA / `react-scripts` в 2026.
- Искать «куда делся index.html» в `src` — у Vite html в корне пакета.
- Тащить в этот спринт тонкую настройку роллера «потому что так в банке».

## Как надо

Проект уже в `01-react/`. Точка входа `index.html` → `src/main.tsx`. Strict Mode включён — эффекты в dev двоятся, это норма, см. [strict-mode](../gotchas/strict-mode-double-effect.md).

В `vite.config` стоит `server.open: true` — при `pnpm dev` браузер откроется сам. Смотреть правки = HMR Vite, отдельный Debug для этого не нужен.

## Шаги

1. `cd 01-react && pnpm dev` — поднимется сервер и откроется браузер.
2. Если сервер уже крутится без вкладки: в VS Code `Cmd+Shift+P` → **Simple Browser: Show** → `http://localhost:5173` (встроенная вкладка, не руками в Chrome).
3. Поменять текст в `src/App.tsx`, сохранить — страница обновляется без F5. Это HMR.
4. Breakpoints / DevTools как отладчик — F5 → конфиг **Chrome: localhost Vite** (нужен запущенный `pnpm dev`). Для дня 1 обычно хватает п.1–3.
5. Сборку `pnpm build` в этот день не обязательно. Когда дойдёшь до капстоуна — один раз проверить, что `tsc -b` проходит.

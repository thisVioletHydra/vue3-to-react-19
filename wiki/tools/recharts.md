# Recharts

## Зачем

Графики для финтеха: таймсерии, бары, real-time обновление props. Вакансии пишут Recharts / ECharts / D3. В курсе — **Recharts**: React-компоненты, быстрее сесть после Vue. ECharts — знаешь что это, не модуль.

## Как не делать

- D3 с нуля «потому что солидно» на 8-часовой смене.
- Хранить 10к точек в Zustand и пушить каждую тик WS без окна/буфера.
- Анимировать всё до 60fps на слабом ноуте compliance-офицера.

## Как надо

`LineChart` / `BarChart` на массиве `{ t, v }`. Обновление — новый массив props (иммутабельно). Для live — буфер последних N точек в `useState` или в WS-хуке.

## Шаги

1. Смена B: `pnpm add recharts`.
2. Дашборд: линия + бар на моке.
3. Подключить обновление из WS-мока (новые точки в хвост, длина ограничена).
4. Чек: график живой, страница не тормозит на 50 точках.

# Storybook

## Зачем

В вакансии — white-label SDK и дока: Storybook, demo-страницы. Показываешь компоненты изолированно, без логина в админку. Для отклика — 2–3 сториса достаточно.

## Как не делать

- Storybook на весь FSD в первую же ночь.
- Дублировать всю бизнес-логику Query внутри сториса без моков.
- Считать Storybook заменой e2e.

## Как надо

Vite+React Storybook. Сторисы на Card / TableRow / Chart с controls. Demo-маршрут в приложении тоже ок. В README — как поднять `npm run storybook`.

## Шаги

1. Смена C: init Storybook под Vite.
2. Три сториса на примитивы/виджеты 1b.
3. Один скрин в README или GitHub.
4. Чек: сторис открывается без бэка.

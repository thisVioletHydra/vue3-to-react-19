# Tailwind

## Зачем

Утилитарные классы в разметке. В вакансиях 2026 часто рядом с Vite/React. Быстрее собрать admin-таблицу и форму, чем раздувать CSS Modules на каждый экран. Во Vue мог быть тот же Tailwind или scoped CSS — здесь просто подключаем в Vite.

## Как не делать

- `@apply` на всё подряд — получаешь CSS Modules другим синтаксисом.
- Тащить сразу shadcn/Ant «потому что в вакансии». Сначала utility + 2–3 своих примитива.
- Смешивать Modules и Tailwind на одном компоненте без правила.

## Как надо

Новые экраны 1b — Tailwind. Дизайн-токены через theme в конфиге, если надо. Компонент: `className="flex gap-2 ..."`.

## Шаги

1. Смена A: поставить Tailwind v4/v3 по актуальной доке Vite+React.
2. Один экран таблицы на utility-классах.
3. Button/Input как простые компоненты с className.
4. Чек: нет глобальных `.item1` в index.css на всю админку.

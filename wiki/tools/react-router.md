# React Router

## Зачем

Vue Router для SPA. Страницы каталога, layout, `:id`, фильтры в query string. После F5 фильтры живые — это прямо из вакансий.

## Как не делать

- Держать фильтры только в `useState` и удивляться пустому поиску после обновления.
- `window.location` руками вместо `Link` / `useNavigate`.
- Копировать Vue `router-view` поиском по проекту — здесь `<Outlet />`.

## Как надо

Layout рисует шапку и `<Outlet />` — дырка, куда вкладывается дочерний маршрут. Список `/`, деталка `/:id`, 404. `useSearchParams` для `q` и `page`. `Link`, не `<a>`, если не уходим с приложения.

## Шаги

1. Ставим, когда дойдёт день 2: `pnpm add react-router` в `01-react` (в чате вместе с кодом, не заранее если ещё не день 2).
2. Обернуть приложение в `BrowserRouter`, вынести layout.
3. Три маршрута: список, деталка, 404.
4. Поиск пишет в `?q=`, обновить страницу — строка поиска на месте. Чек закрыт.

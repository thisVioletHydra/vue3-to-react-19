# pages/catalog — экран каталога

URL: `/main` (index админки). Рамка: `AdminLayout`.

Стейт списка, поиск и форма добавления живут здесь. Фичи/карточки
импортируются снаружи, страница только склеивает.

## Почему каталог — page, а не feature

На этом экране несколько независимых действий: поиск, добавление товара,
«в список». Feature — это одно действие. А экран, который расставляет
несколько фич и держит их общий стейт (список товаров, запрос поиска) —
это page. Каталог именно склеивает: берёт `SearchField` из features,
`ProductCard` из entities и соединяет их своим стейтом.

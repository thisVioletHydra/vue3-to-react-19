# pages/login — экран входа

URL: `/login`. Рамка: `AuthLayout` (центрирование без сайдбара).

## Структура

- `ui/LoginPage.tsx` — сам экран: форма логин/пароль. Export default —
  чтобы `React.lazy` работал без обёрток (объяснение в `app/router.tsx`).
- `index.ts` — вход снаружи: `import { LoginPage } from "../pages/login"`.

## Про нейминг

Папка называется `login` (kebab-case, как принято для папок-слайсов),
компонент внутри — `LoginPage` (PascalCase, как любой React-компонент).
Это просто конвенция читаемости, на работу кода не влияет.

## Что сюда не тащить

Сайдбар, каталог, роутер — им тут не место. Если форма логина когда-нибудь
станет нужна ещё где-то (модалка «сессия истекла»), её можно будет вынести
в `features/login-form`, а страница останется тонкой обёрткой. Пока не надо.

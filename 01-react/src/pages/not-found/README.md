# pages/not-found — экран 404

Показывается, когда URL не совпал ни с одним роутом (путь `*` в карте)
или когда роутер словил ошибку (`errorElement`).

Отдельная папка, потому что это полноценный экран со своим поведением,
а не кусок другой страницы. Из полезного тут обычно: текст «страницы нет»
и ссылка обратно на каталог или логин.

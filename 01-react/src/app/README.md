# app/ — сборка приложения

Это не «ещё одна страница». Это место, где приложение собирается в целое:
кто рендерится первым, какие URL существуют, какая рамка вокруг страниц.
Во Vue-проекте это был бы `main.ts` + `App.vue` + `router/index.ts`.

## Что здесь лежит

### `router.tsx` — карта адресов

Единственное место, которое знает «по какому URL какая страница».
Роутер лежит наверху не случайно: страница не должна знать, по какому
адресу её повесили, а фича тем более. Знает только карта.

### Корень дерева

`main.tsx` → `RouterProvider`. Отдельного `App.tsx` нет: страницы монтирует роутер, рамки — `layouts/`.

### `layouts/` — рамки вокруг страниц

Подробнее в `layouts/README.md`. Коротко: сайдбар админки и центрирование
логина — это не страницы, это оболочки, внутри которых страницы меняются.

### `styles/` — глобальный CSS

Стили, которые действуют на всё приложение (reset, шрифты, переменные).
Стили конкретного компонента живут рядом с ним как `*.module.css`.

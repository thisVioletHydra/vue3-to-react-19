# app/layouts/ — рамки вокруг страниц

Layout — это то, что остаётся на месте, когда страницы под ним меняются.
Точный аналог из Vue: компонент с `<router-view />` внутри. В React ту же
роль играет `<Outlet />` из react-router — дырка, куда роутер вставляет
текущую страницу.

## Наши два layout'а

### `auth-layout` — рамка для гостя

Без сайдбара. Форма по центру пустого экрана. Внутрь через `<Outlet />`
встанет `LoginPage` (а позже, например, страница регистрации — та же
рамка, другая начинка).

### `admin-layout` — рамка авторизованного

Слева сайдбар с навигацией и кнопкой «Выйти», справа `<Outlet />`,
куда встаёт `CatalogPage` и все будущие страницы админки.

## Почему layout — не page

У страницы есть свой URL и свой контент. У layout'а нет ни того, ни
другого: сам по себе `admin-layout` показывать нечего, он существует
только чтобы обернуть чужой контент. Поэтому он живёт в `app`, рядом
с роутером, который его и использует:

```
/login    → AuthLayout  и внутри LoginPage
/catalog  → AdminLayout и внутри CatalogPage
```

Одна рамка — много страниц. Если завтра появится `/settings`, ты не
копируешь сайдбар, а просто добавляешь страницу ребёнком AdminLayout.

# entities/product — сущность «товар»

Всё, что описывает товар сам по себе, в одном месте.

## Структура

- `model/mockProducts.ts` — тип `Product` (какие у товара поля) и моковые
  данные вместо бэка. `model` = данные и логика, никакого JSX.
- `ui/ProductCard.tsx` — как товар выглядит. Карточка «глупая»: получила
  товар через props, нарисовала. На клик по кнопке зовёт `onAddToList(id)` —
  сообщает наверх, ничего не решая сама.
- `index.ts` — что видно снаружи: тип, моки, карточка. Внутренности
  слайса снаружи не импортируют.

## Зачем model и ui врозь

Тип `Product` нужен и форме добавления (features/add-product), и будущему
API-слою — им не нужен JSX карточки. А карточке не нужно знать, откуда
данные пришли. Разделил — и каждый берёт только своё.

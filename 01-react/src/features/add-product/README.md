# features/add-product — действие «добавить товар»

Форма: название, цена, описание → сабмит → новый товар.

## Почему это feature

Это глагол, действие юзера. Сам товар (тип, карточка) — entity.
Экран, на котором форма стоит — page. А «заполнил и отправил» — feature.

## Ключевая деталь: форма не добавляет товар сама

У неё нет доступа к списку товаров. На сабмите она зовёт колбэк
`onAdd(draft)` — «эй, наверху, юзер хочет добавить вот это». Кто владеет
списком (сейчас App, потом CatalogPage) — тот и добавляет.

Это то же самое, что `emit('add', draft)` во Vue: ребёнок сообщает,
родитель решает. Благодаря этому форму можно воткнуть куда угодно —
она не привязана ни к каталогу, ни к конкретному стору.

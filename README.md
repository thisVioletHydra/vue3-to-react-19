# Vue 3 → React 19

Курс-миграция для фронта с коммерческим Vue 3 (Composition API, Pinia, Vue Router, TypeScript). Цель — стек, который в 2026 ждут в вакансиях: React 19, Vite, Zustand, TanStack Query, React Router, затем Next.js App Router.

Redux в курс не входит. HTML/CSS/JS/TS с нуля не разбираем.

## Структура

- [`wiki/`](wiki/) — план, прогресс, готчи и тулзы трека React
- [`01-react/`](01-react/) — SPA-каталог на Vite + React 19
- [`02-next/wiki/`](02-next/wiki/) — трек Next, отдельно, без смешивания. Приложение появится после ядра React

## Старт

```bash
cd 01-react
npm install
npm run dev
```

Дальше — [`wiki/progress.md`](wiki/progress.md).

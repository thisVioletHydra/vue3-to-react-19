# Vue 3 → React 19

Курс-миграция для фронта с коммерческим Vue 3 (Composition API, Pinia, Vue Router, TypeScript). Цель — стек Vite SPA / финтех-админок 2026: React 19, Zustand, TanStack Query, Router, RHF+Zod, затем Tailwind, charts, WebSocket, Storybook. Next — опционально, не гейт для Vite-вакансий.

Демо-пет = этот репо. Код пишем по сменам в чате и пушим. Redux и автотесты в код не входят.

Карта вакансии ЦФА / admin console: [`wiki/vacancies/cfa-admin-console.md`](wiki/vacancies/cfa-admin-console.md).

## Структура

- [`wiki/`](wiki/) — план ядра, [финтех 1b](wiki/plan-fintech.md), прогресс, готчи, тулзы
- [`01-react/`](01-react/) — SPA (сначала каталог, потом admin-console кусок)
- [`02-next/wiki/`](02-next/wiki/) — трек Next отдельно; не блокер для Vite-финтех

## Старт

```bash
cd 01-react
npm install
npm run dev
```

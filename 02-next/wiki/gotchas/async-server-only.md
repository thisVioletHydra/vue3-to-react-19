# async только у серверного компонента

## В чём проблема

`export default async function Page()` на сервере — норма: можно `await fetch`. Клиентский компонент с `async` нельзя. Хуки и await в одной клиентской функции не живут.

## Как не делать

- `'use client'` + `async function`.
- `await fetch` в теле клиентского компонента.
- Копировать SPA-привычку «всё в одном файле с хуками и await».

## Как надо

Сервер: async page/layout, fetch там. Клиент: Query или action. Граница `'use client'` — место, где появляются хуки, не место для await данных страницы.

# Query поверх серверного fetch без причины

## В чём проблема

Сервер уже отдал список HTML. Клиентский `useQuery` на тот же URL без живого поиска / фокуса вкладки / бесконечного скролла — второй канал правды и лишний водопад.

## Как не делать

- Дублировать RSC-список в Query «на всякий».
- Копировать серверный `data` в Zustand.

## Как надо

Query на острове, которому нужны хуки: поиск по мере ввода, infinite scroll. Первый HTML списка — сервер. После action список обновляет revalidate, не клиентский кэш Query, если Query там нет.

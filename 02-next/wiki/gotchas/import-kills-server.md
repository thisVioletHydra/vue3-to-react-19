# Import серверного в клиентский файл убивает сервер

## В чём проблема

`'use client'` делает клиентом этот модуль и **всё, что он импортирует**. Импортнул список с `fetch` из кнопки — список больше не серверный, fetch в браузере, бандл раздулся.

`children` с сервера в клиентскую обёртку — ок. Слот уже готовый, клиент его не импортировал.

## Как не делать

- `'use client'` на `layout` «на всякий».
- Импорт `ProductList` в файл кнопки.
- Думать «я хочу чтобы файл был серверным» без смотрения на граф импортов.

## Как надо

Серверный `page` рендерит `<ClientChrome>{serverList}</ClientChrome>`. Импорт ≠ слот. Layout может быть серверным, `page` серверным, остров — отдельный клиентский файл, который не импортирует серверный fetch.

# Синглтон на сервере — чужие данные

## В чём проблема

`let cart = []` в модуле на сервере — один массив на всех пользователей процесса Node. Во Vite SPA это кривой стор. Здесь это дыра в данных.

## Как не делать

- `export let cache = ...` с пользовательским стейтом в серверном файле.
- Тащить клиентский модуль-синглтон на сервер через общий импорт.

## Как надо

Корзина — клиентский Zustand в `'use client'`. Серверные данные — fetch/action на запрос. Не глобальная переменная файла.
